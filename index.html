Comment ça marche
Le nom du salon suffitVos collègues ouvrent l’onglet Discussion, entrent leur prénom et le même nom de salon : ils arrivent directement avec vous. Pas de compte, pas de code à copier.
Messages gardés 14 joursUn collègue qui arrive plus tard retrouve les messages des 14 derniers jours, même si personne d’autre n’est connecté.
Trois relais en même tempsChaque message part par trois relais publics : il suffit qu’un seul passe. Si le Wi-Fi bloque tout, passez en 4G/5G.
Chiffré sur l’appareilLes messages sont chiffrés (AES-256) avant d’être envoyés. Ajoutez un code secret pour que personne d’autre ne puisse les lire.
